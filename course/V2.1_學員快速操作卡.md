## Colab Secrets 設定方式

1. 打開 Colab Notebook
2. 左側點「🔑 Secrets」
3. 新增 Secret
4. Name：`GROQ_API_KEY`
5. Value：貼上你的 Groq API Key
6. 開啟 Notebook access

之後 Notebook 會自動使用：

```python
from google.colab import userdata
GROQ_API_KEY = userdata.get("GROQ_API_KEY")
```

不需要再手動貼 API Key 到程式碼或輸入框。
