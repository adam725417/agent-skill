# 企業 AI Agent 實戰 V2｜學員操作講義
## Google ADK + Groq API + Agent Skills + MCP + LINE

## Final Project
LINE → Google ADK Agent → Agent Skill → MCP Tools → 報價決策 → LINE

## 技術角色
- **Google ADK（Agent Development Kit）**：Agent 執行框架
- **Groq API**：LLM 推論平台
- **LiteLLM**：ADK 與 Groq 之間的模型 connector
- **Agent Skill**：工作方法、SOP、參考資料與腳本
- **MCP（Model Context Protocol，模型上下文協定）**：企業 Tools 標準介面
- **LINE Messaging API**：使用者下指令與收報告的入口

## 為什麼 V2 不再把 Skill 當一個單獨 SOP 檔？
ADK 已原生支援 Agent Skills。Skill 建議結構：

skills/
└── quotation-decision/
    ├── SKILL.md
    ├── references/
    ├── scripts/
    └── assets/

`SKILL.md` 必須包含 YAML frontmatter：
- `name`
- `description`

本課會直接使用 ADK 的 `load_skill_from_dir()` 與 `SkillToolset`。

## 模型
預設：
`groq/openai/gpt-oss-20b`

原因：
- Groq 目前支援
- 支援 Tool Use
- 適合 agentic workflow
- 成本相對低，適合課堂

若未來模型異動，只要修改 `GROQ_MODEL`，不必重寫 Agent 架構。

## Skill 與 MCP 最重要的差別
Skill：
「報價時要先查什麼？如何判斷？什麼情況要 REVIEW？」

MCP：
「客戶信用是多少？成本是多少？產能是多少？」

## 企業治理
- LLM 不得自行創造 ERP / CRM / MES 資料。
- Tool / MCP 回傳才是企業事實來源。
- Skill 定義企業工作方法。
- REVIEW 必須有人員介入。
- 課堂輸出是 Decision Support，不是正式報價承諾。

## 去哪裡找 Skill？
建議從以下來源學習：
1. ADK 官方 Skills 文件與 samples
2. Agent Skills 開放規格（agentskills.io）
3. Google Agents CLI 提供的 development skills
4. GitHub 上公開的 Agent Skills repository

下載外部 Skill 前務必檢查：
- SKILL.md
- frontmatter
- scripts/
- references/
- 外部網路連線
- API keys
- 寫檔／執行指令權限
- repository 可信度

Skill 可能包含可執行 script，因此應像審查程式套件一樣審查，不應把它當成單純 Prompt。
