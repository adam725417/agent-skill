# AI Agent Academy：Agent × MCP × Skill 教學網站

此專案為不需建置工具的單頁靜態網站，可直接開啟 `index.html`，或部署到 GitHub Pages。

## 部署
1. 將此資料夾所有檔案推送至新 GitHub Repository 根目錄。
2. 在 GitHub Repository Settings → Pages → Deploy from a branch，選擇 main / root。
3. 進入產生的 GitHub Pages 網址即可使用。

## Colab 實作
點選左側 Colab 實作中心下載四份 ipynb，進入 https://colab.research.google.com/ → 上傳筆記本。
執行 Notebook 上傳資料步驟，請上傳 `course/quotation_agent_v2_runtime.zip`。
在 Colab Secrets 設定 `GROQ_API_KEY`。LINE/ngrok 資訊依 LAB04 指示設定。

注意：網站是教材及資源目錄，不會替您在 Colab 自動執行程式；Notebook 的依賴、服務憑證與外部 API 仍需實機確認。
